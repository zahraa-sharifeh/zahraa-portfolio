# Zahraa Sharifeh — portfolio

Personal engineering site. Built for applications that care about production React, TypeScript, Postgres tenancy, Node, and React Native.

Live products featured: [NGOreality](https://www.ngoreality.com/), [QSME](https://qsme.io), [Lebalist](https://lebalist.com), [City Care](https://citycarelb.netlify.app).

## Stack

Vite · React · TypeScript · Tailwind CSS v4 · Framer Motion · React Router

Layout adapted from [Jhanvi Shah’s illustration portfolio template](https://www.figma.com/community/file/1318529372146880502/illustration-based-portfolio-website-template) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)).

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5174

```bash
npm run build
npm run preview
```

`npm run resume` regenerates `public/Zahraa_Sharifeh_Resume.pdf`.

## Deploy

Static Vite app. On Vercel, import this repo (SPA rewrites are in `vercel.json`).
